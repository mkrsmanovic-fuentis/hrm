<Update label="2026-11-10 16:40" description="SPE-15 · Account setup and password reset" tags={["Frontend", "API", "Docs"]}>
  New employees now set their own password from an invite link, valid for 7 days. Administrators can resend invites and see each person's invite status, and changing the email of someone who hasn't set a password sends a fresh invite. Anyone can reset a forgotten password with a single-use link, valid for 1 hour, which signs them out everywhere else. In the demo, the links appear on screen instead of being emailed.

  Commit: [dc8a4f2](https://github.com/mkrsmanovic-fuentis/hrm/commit/dc8a4f257dc9a5d870774ec9f47206abbfe19477)
</Update>

<Update label="2026-11-10 16:31" description="SPE-19 · Checks before activation" tags={["Frontend", "API", "Docs"]}>
  A questionnaire can now be activated only when it's complete: it has questions, each with text, at least two answer options and exactly one correct answer, and its topic is active. The questionnaire's page lists what needs fixing and jumps straight to each question. A questionnaire's first activation is now recorded as "activated" in the audit log. The question editor also stops a save if employees started the questionnaire while you were editing, and asks you to confirm the new version.

  Commit: [a3e8477](https://github.com/mkrsmanovic-fuentis/hrm/commit/a3e84777e1b5c665dbdc24dab3a9f15e88d2954b)
</Update>

<Update label="2026-11-10 16:05" description="SPE-18 · Question editor" tags={["Frontend", "API", "Docs"]}>
  Administrators can now add, edit, remove and reorder questions and answer options on a questionnaire's page, each question with exactly one correct answer and optional feedback. If employees have already taken the questionnaire, saving creates a new version after a warning, and earlier results never change. The editor warns before you leave with unsaved changes.

  Commit: [697a5b6](https://github.com/mkrsmanovic-fuentis/hrm/commit/697a5b640440cdc6e6b8a18b7f87a413a7b1a90b)
</Update>

<Update label="2026-11-10 15:35" description="SPE-17 · Questionnaires" tags={["Frontend", "API", "Docs"]}>
  Administrators can now list, search and filter questionnaires, create them as inactive drafts, and edit their settings on a detail page: title, description, topic, passing score (80% by default) and optional time limit. A questionnaire can't be activated until it has questions. Deactivated questionnaires can't be assigned, but training already assigned can still be completed.

  Commit: [2b7427b](https://github.com/mkrsmanovic-fuentis/hrm/commit/2b7427bb451ee602332119956f4097c0fe3d62b8)
</Update>

<Update label="2026-11-10 15:24" description="SPE-14 · Employees" tags={["Frontend", "API", "Docs"]}>
  Administrators can now list, search and filter employees, create them with a role and department, edit them, and deactivate or reactivate them. The list shows each person's assigned and completed training. Creating an employee sends an invite. Deactivating an employee signs them out everywhere at once. Administrators can't deactivate themselves or change their own role.

  Commit: [6732a51](https://github.com/mkrsmanovic-fuentis/hrm/commit/6732a51be6021f125ef988560b78b28e50651d44)
</Update>

<Update label="2026-11-10 15:03" description="SPE-16 · Topics" tags={["Frontend", "API", "Docs"]}>
  Administrators can now create, edit, deactivate and reactivate security topics, each with an optional icon, and see how many questionnaires each topic has. Employees see only active topics. The demo data includes an inactive topic, Clean Desk Policy.

  Commit: [5658c7a](https://github.com/mkrsmanovic-fuentis/hrm/commit/5658c7a325d00378a5654d82e57b14108570c99b)

<Update label="2026-11-10 14:47" description="SPE-13 · Departments" tags={["Frontend", "API", "Docs"]}>
  Administrators can now create, rename, describe, deactivate and reactivate departments, and see how many people each one has. This is the first page for changing data, and it sets the pattern for the admin pages that follow: a searchable list, a side drawer for editing, and a confirmation before deactivating. Every change is recorded in the audit log.

  Commit: [b20ceec](https://github.com/mkrsmanovic-fuentis/hrm/commit/b20ceec3d7264c34318328ae0d391ed66cc487ad)

<Update label="2026-11-10 14:32" description="SPE-11 · Roles and access" tags={["Frontend", "API", "Docs"]}>
  Administrators and employees now have separate areas, each with its own home page and side menu. Opening a page meant for the other role shows a "No access" page without signing you out. Sessions end automatically when they expire, even on an idle page, and signing in, out or switching roles carries over to other open tabs. The business rules now include an access matrix for the backend.

  Commit: [b903e0a](https://github.com/mkrsmanovic-fuentis/hrm/commit/b903e0afb7b23471e85baed49dcf834ebc908dfe)
</Update>
