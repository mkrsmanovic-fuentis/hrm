title: "HRM Platform"
description: "Security awareness training through topic-based questionnaires."
icon: "house"
---

HRM Platform helps organizations teach employees about cybersecurity risks. Administrators assign questionnaires on security topics, such as phishing or password security. Employees complete them and must reach a passing score.

<Note>
  The platform is in development. The current version is a frontend demo with dummy data. Pages are added here as features are built.
</Note>
