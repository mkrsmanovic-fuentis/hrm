This page is for administrators. A questionnaire is a set of multiple-choice questions on one security topic, with a passing score and an optional time limit. The **Questionnaires** page lists every questionnaire, and each questionnaire has its own page with its settings.

This page covers the settings, the questions, and activating and deactivating a questionnaire.

## Before you start

- You need to be signed in as an administrator. Employees cannot open these pages.
- You need at least one active topic. See [Manage topics](/user-guide/manage-topics).
- Open **Questionnaires** in the side navigation.

## See your questionnaires

The list shows each questionnaire's **Title**, **Topic**, number of **Questions**, **Passing score**, **Status** and the date it was **Created**.

- **Search by title** finds questionnaires whose title contains the text you type. Upper and lower case do not matter.
- **Filters** shows only the questionnaires of one **Topic**, or only **Active** or **Inactive** ones.
- Select a column header to sort by it. Select it again to reverse the order.
- Select a row, or the arrow icon at the end of it, to open the questionnaire's page.

## Create a questionnaire

<Steps>
  <Step title="Select New questionnaire">
    The button is at the top right of the page. A panel opens on the right.
  </Step>
  <Step title="Fill in the form">
    **Title** is required, up to 200 characters. Titles do not have to be unique: two questionnaires can have the same title, for example in different topics.

    **Description** is optional, up to 2,000 characters.

    **Topic** is required. Only active topics can be chosen. Inactive topics are listed, but you cannot pick them.

    **Passing score (%)** is the score an employee needs to pass: a whole number from 1 to 100. It starts at **80**.

    **Time limit (minutes)** is optional, from 1 to 480 minutes. Leave it empty for no time limit.
  </Step>
  <Step title="Select Create questionnaire">
    A message confirms the new questionnaire, and its page opens. The questionnaire is **Inactive**: it is a draft until you activate it.
  </Step>
</Steps>

## Change the settings

<Steps>
  <Step title="Open the questionnaire">
    Select its row in the list.
  </Step>
  <Step title="Select Edit settings">
    The same form opens, with the current settings. The same rules apply as when you create a questionnaire. You can move the questionnaire to another active topic. If its topic was deactivated, it can stay in that topic.
  </Step>
  <Step title="Select Save changes">
    The panel closes and a message confirms the change. If you changed nothing, the panel just closes. To leave without saving, select **Cancel**.
  </Step>
</Steps>

Changing the passing score does not change earlier results. Each attempt keeps the passing score it started with.

## Edit the questions

The **Questions** section of a questionnaire's page lists its questions in the order employees see them. You edit them all at once, then save them together.

Each question has:

- **Question**: the text, up to 1,000 characters. Required.
- **Answer options**: at least two, each up to 500 characters.
- **Correct answer**: exactly one of the answer options. It is marked **Correct**.
- **Feedback for a wrong answer**: optional, up to 2,000 characters. Employees see it when they answer the question wrong.

<Steps>
  <Step title="Open the questionnaire">
    Select its row in the list. The **Questions** section is under the settings.
  </Step>
  <Step title="Add or change questions">
    - Select **Add question** to add one at the end. It starts with two empty answer options.
    - Type in **Question**, the **Answer** fields and **Feedback for a wrong answer** to change them.
    - Select **Add answer option** to add another answer to a question.
    - Choose the right answer in **Correct answer**. Choosing another one moves the mark: only one answer can be correct.
    - Use the arrow buttons next to a question or an answer to move it up or down, and the bin button to remove it.

    The buttons work with the keyboard too: press Tab to reach them, and Enter or Space to use them. A badge says **Unsaved changes** until you save.
  </Step>
  <Step title="Select Save questions">
    A message confirms the save. If something needs fixing, the fields are highlighted and nothing is saved. To start over, select **Discard changes**.
  </Step>
</Steps>

If you try to leave the page with unsaved changes, you are asked first. Select **Keep editing** to stay, or **Leave without saving** to lose the changes.

### Questions of an active questionnaire

An active questionnaire must stay ready to take. You cannot save it without questions, and each question needs at least two answer options with one correct answer.

A draft, an inactive questionnaire, can be saved unfinished, so you can work on it over time.

### When employees have already taken it

Questionnaires keep **versions** of their questions, so that results always match the questions employees answered. The **Questions** section shows the current version, and how many attempts use it.

- **No one has taken the current version yet:** your changes replace its questions.
- **Employees have taken it, or started it:** your changes are saved as a new version, for example version 2. Before saving, a dialog tells you so: select **Save as version 2** to go ahead, or **Cancel** to keep editing. From then on, new attempts use the new version.

Past attempts and results are kept and never change. An employee who is in the middle of an attempt finishes it on the version they started with.

If an employee starts the questionnaire while you are editing, or it gets a new version (for example another administrator saved its questions after employees had taken it), **Save questions** stops and nothing is saved. Your changes stay on the page, and a message says what changed. If saving now creates a new version, the **Save as version** dialog opens so you can confirm it. Otherwise, check your changes and select **Save questions** again.

Two administrators editing the same questions at the same time, before anyone has taken them, are not detected: the later save replaces the earlier one.

## Activate a questionnaire

A questionnaire must be active before it can be assigned. It can be activated only when it is ready to take:

- it has at least one question;
- every question has text, at least two answer options with text, and exactly one correct answer;
- its topic is active.

<Steps>
  <Step title="Open the questionnaire and select Activate">
    You can also select the circular arrow icon in its row in the list. If the questionnaire is not ready yet, the icon opens its page instead, so you can see what needs fixing.
  </Step>
  <Step title="Confirm">
    Select **Activate**. The questionnaire is active, and it can be assigned to employees.
  </Step>
</Steps>

### When Activate is not available

If the questionnaire is not ready, **Activate** is greyed out, and a box at the top of the page says **This questionnaire can't be activated yet**. It lists every problem, for example "Question 2 has no correct answer. Choose one."

<Steps>
  <Step title="Go to the question">
    Select **Go to question 2** next to a problem. The page scrolls to that question in the **Questions** section and outlines it. The same problems are shown on the question itself.
  </Step>
  <Step title="Fix it and save">
    Change the question, for example add an answer option or choose the **Correct answer**, then select **Save questions**. The list of problems updates after the save.
  </Step>
  <Step title="Activate">
    When nothing is left to fix, the box goes away and **Activate** is available.
  </Step>
</Steps>

If the questionnaire has no questions yet, add them in the **Questions** section first.

If its topic is inactive, either select **Choose another topic** to move the questionnaire to an active topic in **Edit settings**, or select **Go to Topics** and reactivate the topic. See [Manage topics](/user-guide/manage-topics).

## Deactivate a questionnaire

Deactivate a questionnaire you no longer want to assign.

<Steps>
  <Step title="Open the questionnaire and select Deactivate">
    You can also select the power icon in its row in the list.
  </Step>
  <Step title="Confirm">
    The dialog explains what happens. Select **Deactivate** to go ahead, or **Cancel** to keep it active.
  </Step>
</Steps>

An inactive questionnaire cannot be assigned. Employees who already have it assigned can still complete it, and all results are kept. You can activate it again at any time.

## Good to know

- Questionnaires are never deleted. Deactivate them instead.
- Every change you make is recorded with your name and the time, so it is clear who changed what.
- The rules are in [Business rules](/developer-guide/business-rules#questionnaires) and [Questionnaire versions](/developer-guide/business-rules#questionnaire-versions).
